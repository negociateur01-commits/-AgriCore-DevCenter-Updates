# AgriCore Dev Center — Official Windows Updates

Public distribution repository for **AgriCore Dev Center**, a local Farming Simulator 25 mod-development and diagnostics application.

**Status: distribution channel created — no stable Windows release is published yet.**

### Published assets (after the first verified release)

- `AgriCore_DevCenter_Setup_*.exe` — Windows installer.
- `AgriCore_DevCenter_*.acupdate` — in-app update package.
- `latest.json` — signed update manifest published in the `updates` release.

The `latest.json` manifest and update package will be checked against a pinned Ed25519 public key and the expected SHA-256 hash. Never install a package from an untrusted sender. No signing private key belongs in this repository.

**The application source remains private.** Releases are generated by a Windows GitHub Actions workflow in the private source repository and uploaded here after validation.

### Security / reporting

Do not post access tokens, signing keys, secrets, or private FS25 mods in public Issues.

No manual download or installation is necessary yet. The first release will appear in the [Releases](https://github.com/negociateur01-commits/-AgriCore-DevCenter-Updates/releases) section once verified.
